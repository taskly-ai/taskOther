## Стр. 20

```text
Уравнение фазового равновесия
✓
Любой процесс протекает до тех пор, пока не установится
состояние его равновесия.
✓
Фазовое равновесие определяется правилом фаз, согласно
которому число компонентов (K) в системе плюс 2 равно числу фаз
(Ф) плюс число параметров в системе (N), которое можно менять,
не нарушая равновесия в системе.
K + 2 = Ф + N
✓
Правило фаз позволяет определить, какое число параметров можно
изменять, не нарушая равновесие.
✓
Для процессов массообмена характерно наличие двухфазных систем,
для которых Ф = 2. Тогда для двухкомпонентной системы K = 2, и если
Ф = 2, число параметров N = 2. Поэтому, равновесие определяется
комбинацией следующих параметров:
x − P, x −T, y − x
```
