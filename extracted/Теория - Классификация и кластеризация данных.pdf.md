```text
Метод K-средних
✓
Метод k-средних используется для кластеризации данных на основе алгоритма
разбиения векторного пространства на заранее определенное число кластеров k
1.
Выбирается число кластеров k.
2.
Из исходного множества данных случайно выбираются k объектов (или
произвольных точек), которые служат начальными центрами кластеров.
3.
Для каждого объекта исходного множества определяется ближайший к нему
центр кластера (в метрике Евклида). Объекты, «притянутые» определенным
центром, образуют кластеры.
4.
Вычисляются центроиды — центры тяжести кластеров. Каждый центроид —
это вектор, элементы которого представляют собой средние значения
соответствующих признаков, вычисленные по всем объектам кластера.
5.
Центр кластера смещается в его центроид, после чего центроид становится
центром нового кластера.
6.
Оцениваем качество каждого кластера как сумму квадратов
внутрикластерных расстояний до центра кластера (WCSS).
7.
Шаги 3-6 итеративно повторяются до сходимости по структуре кластеров.
```
