# Автоматизация Aspen HYSYS V15: скрипт `hysys_auto.py`

Скрипт сам строит в твоём HYSYS три сценария из `../out/МХТП_HYSYS_инструкция.docx`, решает их, сравнивает результат с отчётом и ориентиром Пенга–Робинсона и записывает всё в Excel.
- **S1** — три сепаратора: базовый режим, режим 6,0 МПа и исследование P₂ = 4,0…9,5 МПа.
- **S2** — синтез аммиака.
- **S3** — реактор Гиббса.

**Статус: экспериментальный.** Логика проверена на эмуляторе (`python hysys_auto.py selftest`), на настоящем HYSYS V15 скрипт ещё не запускался. Часть вызовов COM может называться в V15 иначе. На каждом шаге скрипт перебирает несколько вариантов, а если ни один не подошёл — пишет, что сделать вручную. Это не оцениваемое задание (0 баллов): если скрипт не пошёл за 15 минут, собери схему руками по инструкции.

## 1. Подготовка (один раз, ≈ 10 мин)
1. **Python 3.9+ для Windows** — с https://www.python.org. При установке поставь галочку **Add Python to PATH**.
2. **Библиотеки.** В командной строке (Win+R → `cmd`):
   ```
   pip install pywin32 openpyxl
   ```
3. **Первый запуск HYSYS.** Один раз открой HYSYS вручную: проверится лицензия и зарегистрируется COM-сервер. Потом HYSYS можно закрыть — скрипт запустит его сам.
4. **Файлы.** Скачай ветку с GitHub (Code → Download ZIP) и распакуй, например в `C:\sharaga`. Нужна папка `07_МХТП\hysys`.

## 2. Запуск
Открой `cmd`, перейди в папку и запусти:
```
cd C:\sharaga\07_МХТП\hysys
python hysys_auto.py diag      ← проверка связи (5 сек): должен напечатать версию HYSYS
python hysys_auto.py all       ← построить и посчитать S1, S2, S3 (≈ 2–5 мин)
```
Можно запускать и двойным щелчком по `run_hysys.bat`: без параметров он покажет справку. Через командную строку: `run_hysys.bat all`.

Отдельные сценарии: `python hysys_auto.py s1` (или `s2`, `s3`).

**Что появится в папке:**

| Файл | Что это |
|---|---|
| `hysys_results.xlsx` | Листы «S1 база», «S1 6,0 МПа», «S2 аммиак», «S3 Гиббс»: Отчёт / Ориентир PR / HYSYS / отклонение. Лист «S1 исследование P2» — таблица и график |
| `S1_separators.hsc`, `S2_ammonia.hsc`, `S3_gibbs.hsc` | Файлы HYSYS: открыть, посмотреть схему, сделать скриншоты |
| `hysys_log.txt` | Журнал: какие шаги прошли (✓), какие нет (✗) |

## 3. Как понять результат
- **S2 (аммиак)** — главная проверка. NH₃ ≈ 1,6691 kgmole/h, y(NH₃) ≈ 0,5896, превращение N₂ ≈ 66,8 %. Совпадение до 3–4-го знака означает, что HYSYS решил то же уравнение, что и отчёт.
- **S3 (Гиббс)** — x ≈ 0,79, K ≈ 1,66. Разница в 3-м знаке нормальна: у HYSYS своя база энергий Гиббса.
- **S1 (сепараторы)** — с отчётом не совпадёт, и это ожидаемо (инструкция, разд. 2.4). Сравнивать надо со столбцом «Ориентир PR».
  - При 9,8 МПа сырьё однофазное: e₁ = 1, Liq1 = 0.
  - При 8,7 МПа третий сепаратор однофазный: Gas3 будет 0 или ≈ 80.
  - При 6,0 МПа: e₂ ≈ 0,862, e₃ ≈ 0,541, Gas3 ≈ 46,7 kgmole/h.

## 4. Если что-то пошло не так

### 4.0 Сам HYSYS не открывается ярлыком (заставка мелькает и исчезает)
Пока HYSYS не стартует вручную, скрипт работать не может. Ошибка `Недопустимая строка с указанием класса` означает, что COM-сервер HYSYS не зарегистрирован в Windows. Чинить по порядку:

1. **Узнать причину.** Пуск → «Просмотр событий» → Журналы Windows → Приложение → красная ошибка с `AspenHysys.exe`. Там будет «Имя сбойного модуля»:
   - `clr.dll`, `KERNELBASE.dll` с исключением .NET → установить **.NET Framework 4.8.1**;
   - `msvcp140.dll`, `vcruntime140.dll`, `ucrtbase.dll` → установить **Microsoft Visual C++ Redistributable 2015–2022**, x64 и x86 (с сайта Microsoft).
2. **Лицензия.** Пуск → **aspenONE SLM License Manager** (или SLM License Profiler) → проверить, что есть доступная лицензия на HYSYS. Energy Analyzer и Flare System Analyzer могут открываться без лицензии на HYSYS, поэтому их запуск ничего не доказывает. Лицензию выдаёт вуз (сервер лицензий, часто через VPN) — уточни на кафедре или в ИТ-службе.
3. **Первый запуск от администратора.** Правой кнопкой по ярлыку HYSYS → «Запуск от имени администратора». Первый старт донастраивает компоненты.
4. **Сброс пользовательских настроек.** Закрыть все программы Aspen, переименовать папку `%APPDATA%\AspenTech` (вставить путь в адресную строку проводника), запустить снова.
5. **Если HYSYS открылся, а скрипт всё равно пишет про «строку класса»** — зарегистрировать COM-сервер. В командной строке **от имени администратора**:
   ```
   "C:\Program Files\AspenTech\Aspen HYSYS V15\AspenHysys.exe" /regserver
   ```
   Путь — где у тебя лежит `AspenHysys.exe`: правая кнопка по ярлыку → «Расположение файла». Затем снова `py hysys_auto.py diag`. Скрипт и сам ищет в реестре все COM-имена HYSYS и пишет их в `hysys_diag.txt`.
6. **Не помогло** — переустановка или «Восстановить» в aspenONE Installer.

**Что прислать мне:** текст ошибки из «Просмотра событий» (п. 1) и `hysys_diag.txt`.

### 4.1 Ошибки скрипта

| Сообщение | Что сделать |
|---|---|
| `Нужен пакет pywin32` | `pip install pywin32` |
| `Не удалось подключиться к HYSYS через COM` | Один раз открыть HYSYS вручную; запускать `cmd` **без** «от имени администратора»; проверить, что установлена именно Aspen HYSYS, а не только Aspen Plus |
| `✗ компоненты …` или `✗ Peng-Robinson` | В V15 базис создаётся иначе. Обход: вручную создать Component List и Fluid Package (инструкция, разд. 1.2–1.3), сохранить пустой файл и прислать мне `hysys_log.txt` |
| `✗ набор реакций Set-1 …` (S2) | Обычное дело: реакции через COM задаются нестабильно. Скрипт достроит остальное. Реакцию создай руками по таблице 5 инструкции (разд. 3.1), в реакторе ERV-100 выбери Set-1, сохрани файл и запусти `python hysys_auto.py read s2 S2_ammonia.hsc` |
| `✗ аппарат … (separator/cooler/…)` | Неверное внутреннее имя типа аппарата. Добавь этот аппарат на схему руками, запусти `python hysys_auto.py diag` (при открытом файле) и пришли `hysys_diag.txt` — там будет правильное имя (TypeName), я поправлю скрипт |
| Числа «—» в Excel | Поток не рассчитан: открыть `.hsc` и посмотреть, какой объект жёлтый или красный (не хватает спецификации) |

**Режим чтения ручной схемы.** Если собрал схему руками по инструкции (имена потоков как в ней: Feed, Feed2, Feed3, Gas3, Liq1… / Feed1, Vap1 / Vap1), скрипт может просто прочитать её и сравнить с отчётом:
```
python hysys_auto.py read s1 мой_файл.hsc
python hysys_auto.py read s2 мой_файл.hsc
python hysys_auto.py read s3 мой_файл.hsc
```

**Что прислать для доработки:** `hysys_log.txt` и `hysys_diag.txt` — текст или скриншот.
