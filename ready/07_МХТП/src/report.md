```python
def sse(y, yfit):
    """Остаточная сумма квадратов SSE."""
    return float(np.sum((np.asarray(y) - np.asarray(yfit)) ** 2))

def r2_score(y, yfit):
    """Коэффициент детерминации R² = 1 − SSE/TSS."""
    y = np.asarray(y)
    return 1.0 - sse(y, yfit) / float(np.sum((y - y.mean()) ** 2))
```

Во всех задачах на построение моделей используются остаточная сумма квадратов и коэффициент детерминации:

$$SSE = \sum_{i=1}^{n} \left( y_i - \hat{y}_i \right)^{2}, \qquad R^{2} = 1 - \frac{SSE}{\sum_{i=1}^{n} \left( y_i - \bar{y} \right)^{2}},$$

где $y_i$ – экспериментальное значение отклика в $i$-й точке; $\hat{y}_i$ – значение, рассчитанное по модели; $\bar{y}$ – среднее экспериментальное значение; $n$ – число точек. Единицы $SSE$ – квадрат единиц отклика, $R^{2}$ безразмерен.

**Метод.** Модель ищется в виде полинома

$$C(T) = a_0 + a_1 \cdot T + a_2 \cdot T^{2} + a_3 \cdot T^{3} + a_4 \cdot T^{4},$$

где $C$ – мольная теплоёмкость, Дж/(моль∙К); $T$ – температура, К; $a_0, \ldots, a_4$ – эмпирические коэффициенты, единицы $a_k$ – Дж/(моль∙К^k+1^). Коэффициенты находятся методом наименьших квадратов (минимум $SSE$) [4] функцией numpy.polyfit; для полинома задача линейна по коэффициентам и решается без начального приближения.

Средняя теплоёмкость по определению

$$\langle C \rangle = \frac{\int_{T_0}^{T} C \, dT}{T - T_0},$$

где $\langle C \rangle$ – средняя теплоёмкость в интервале, Дж/(моль∙К); $T_0 = 50$ К и $T = 1300$ К – границы интервала. Интеграл полинома берётся аналитически (функция numpy.polyint строит первообразную):

$$\int_{T_0}^{T} C \, dT = \sum_{k=0}^{4} \frac{a_k}{k + 1} \cdot \left( T^{k+1} - T_0^{k+1} \right).$$

Интеграл по таблице без модели вычисляется по формуле трапеций для неравномерной сетки:

$$\int_{T_0}^{T} C \, dT \approx \sum_{i=1}^{n-1} \frac{C_i + C_{i+1}}{2} \cdot \left( T_{i+1} - T_i \right),$$

где $C_i$ – табличная теплоёмкость при температуре $T_i$, Дж/(моль∙К); $n = 16$ – число точек таблицы.

**Программа.**

```python
# T, К и C, Дж/(моль·К) (в шапке задания ошибочно «кДж/кг К»)
T1_T = np.array([50, 100, 150, 200, 273.15, 300, 400, 500, 600, 700, 800, 900,
                 1000, 1100, 1200, 1300])

T1_C = np.array([34.16, 41.3, 48.79, 56.07, 68.74, 73.93, 94.01, 112.59, 128.7,
                 142.67, 154.77, 163.35, 174.6, 182.67, 189.74, 195.85])

M_C3H8 = 44.097                     # молярная масса пропана, г/моль

def t1z1(deg=4, T0=50.0, T=1300.0):
    p = np.polyfit(T1_T, T1_C, deg)                  # коэффициенты от старшей степени
    C_fit = np.polyval(p, T1_T)
    P = np.polyint(p)                                # первообразная полинома
    I_poly = np.polyval(P, T) - np.polyval(P, T0)    # интеграл C dT, Дж/моль
    C_poly = I_poly / (T - T0)                       # <C> по модели
    I_trap = trapezoid(T1_C, T1_T)                   # интеграл по таблице (трапеции)
    C_trap = I_trap / (T - T0)
    I_trap_poly = trapezoid(C_fit, T1_T)             # трапеции по значениям полинома
    return dict(p=p, C_fit=C_fit, resid=T1_C - C_fit, R2=r2_score(T1_C, C_fit),
                SSE=sse(T1_C, C_fit), I_poly=I_poly, C_poly=C_poly,
                I_trap=I_trap, C_trap=C_trap,
                delta_rel=abs(C_poly - C_trap) / C_trap * 100,
                # погрешность метода трапеций
                err_trap_rule=(I_trap_poly - I_poly) / (T - T0),
                # вклад остатков модели
                err_model=(I_trap - I_trap_poly) / (T - T0),
                C_poly_mass=C_poly / M_C3H8, C_trap_mass=C_trap / M_C3H8)
```

## 1.2 Задание 2. Содержание воды в дистилляте отпарной колонны

**Условие.** Построить эмпирическую модель зависимости содержания воды в дистилляте $y$ от расхода пара $x$ (таблица 4) в форме

$$y = a \cdot \left( \ln \frac{x}{b} \right)^{-2/3},$$

где $y$ – содержание воды в дистилляте, доли (безразмерно); $x$ – расход пара, кг/с; $a$ – эмпирический коэффициент (безразмерен); $b$ – эмпирический параметр, кг/с. Предложить другую функциональную форму модели.

| x, кг/с | y |
|:---:|:---:|
| 0,263 | 0,34 |
| 0,294 | 0,32 |
| 0,321 | 0,24 |
| 0,367 | 0,20 |
| 0,429 | 0,16 |
| 0,608 | 0,11 |
| 1,330 | 0,06 |
| 1,360 | 0,04 |

: Таблица 4 – Экспериментальные данные [1]

**Метод.** Модель нелинейна по параметру $b$, поэтому используется нелинейный метод наименьших квадратов – функция scipy.optimize.curve_fit (итерационная минимизация $SSE$ методом доверительной области). Модель определена только при $\ln(x/b) > 0$, то есть $b < x_{\min} = 0{,}263$ кг/с, – это ограничение задано параметром bounds.

Начальное приближение имеет решающее значение. Линеаризация $y^{-3/2} = a^{-3/2} \cdot \ln x - a^{-3/2} \cdot \ln b$ даёт $b = 0{,}2884$ кг/с, что больше $x_{\min} = 0{,}263$ кг/с, – недопустимое значение: возведение в степень $-3/2$ многократно усиливает вес малых значений $y$ (точка $y = 0{,}04$ превращается в 125). Поэтому использован приём разделения переменных: при фиксированном $b$ модель линейна по $a$, и оптимальное $a(b) = \sum g_i \cdot y_i / \sum g_i^{2}$, где $g_i = \left( \ln(x_i / b) \right)^{-2/3}$. Перебором $b$ на сетке от 0,001 до 0,262 кг/с найдено начальное приближение $a_0 = 0{,}1264$, $b_0 = 0{,}2144$ кг/с, которое затем уточнено curve_fit.

Для сравнения построены три альтернативные модели с той же качественной зависимостью (монотонное убывание $y$ с ростом расхода пара):

- степенная $y = a \cdot x^{b}$ ($a$ – доли при $x = 1$ кг/с; $b$ – безразмерный показатель степени);
- гипербола со сдвигом $y = a / (x - c)$ ($a$ – кг/с; $c$ – кг/с, расход пара, при котором модель теряет смысл, аналог $b$ заданной модели);
- экспонента с асимптотой $y = a \cdot e^{-b \cdot x} + c$ ($a$, $c$ – доли; $b$ – с/кг).

Модели с разным числом параметров $k$ сравниваются по скорректированному коэффициенту детерминации и информационному критерию Акаике:

$$R^{2}_{\text{скор}} = 1 - \left( 1 - R^{2} \right) \cdot \frac{n - 1}{n - k}, \qquad AIC = n \cdot \ln \frac{SSE}{n} + 2 \cdot k,$$

где $n = 8$ – число точек; $k$ – число параметров модели. Лучшей считается модель с наибольшим $R^{2}_{\text{скор}}$ и наименьшим $AIC$.

**Программа.**

```python
X2 = np.array([0.263, 0.294, 0.321, 0.367, 0.429, 0.608, 1.33, 1.36])   # x, кг/с

Y2 = np.array([0.34, 0.32, 0.24, 0.20, 0.16, 0.11, 0.06, 0.04])        # y, доли

def m_given(x, a, b):
    """Заданная модель y = a·(ln(x/b))^(-2/3)."""
    return a * np.log(x / b) ** (-2.0 / 3.0)

def m_power(x, a, b):
    """Степенная модель y = a·x^b."""
    return a * x ** b

def m_hyper(x, a, c):
    """Гипербола со сдвигом y = a/(x − c)."""
    return a / (x - c)

def m_exp(x, a, b, c):
    """Экспонента с асимптотой y = a·exp(−b·x) + c."""
    return a * np.exp(-b * x) + c

def t1z2():
    xmin = X2.min()
    # линеаризация y^(-3/2) = a^(-3/2)·ln x − a^(-3/2)·ln b
    # даёт b > min(x) — недопустимо
    k, m = np.polyfit(np.log(X2), Y2 ** -1.5, 1)
    a_lin, b_lin = k ** (-2.0 / 3.0), np.exp(-m / k)
    # начальное приближение: при фиксированном b модель линейна по a,
    # a(b) = Σg·y/Σg²; перебор b на сетке (0; min x) и выбор b с минимальной SSE
    b_grid = np.linspace(0.001, 0.999 * xmin, 2000)
    sse_grid = []
    for b in b_grid:
        g = np.log(X2 / b) ** (-2.0 / 3.0)
        sse_grid.append(sse(Y2, (g @ Y2) / (g @ g) * g))
    b0 = b_grid[int(np.argmin(sse_grid))]
    g = np.log(X2 / b0) ** (-2.0 / 3.0)
    a0 = (g @ Y2) / (g @ g)
    specs = {
        "given": (m_given, [a0, b0], ([0, 1e-6], [10, 0.999 * xmin])),   # b < min(x)
        "power": (m_power, [0.05, -1.0], (-np.inf, np.inf)),
        "hyper": (m_hyper, [0.05, 0.1], ([0, -1], [10, 0.999 * xmin])),   # c < min(x)
        "exp":   (m_exp, [1.0, 5.0, 0.05], (-np.inf, np.inf)),
    }
    n, fits = len(X2), {}
    for name, (f, p0, bounds) in specs.items():
        popt, pcov = curve_fit(f, X2, Y2, p0=p0, bounds=bounds, maxfev=20000,
                               ftol=1e-15, xtol=1e-15, gtol=1e-15)
        yf = f(X2, *popt)
        kpar, s = len(popt), sse(Y2, yf)
        r2 = r2_score(Y2, yf)
        fits[name] = dict(p=popt, perr=np.sqrt(np.diag(pcov)), yfit=yf, resid=Y2 - yf,
                          SSE=s, R2=r2, R2adj=1 - (1 - r2) * (n - 1) / (n - kpar),
                          AIC=n * np.log(s / n) + 2 * kpar, k=kpar)
    return dict(a0=a0, b0=b0, a_lin=a_lin, b_lin=b_lin, fits=fits)
```

## 1.3 Задание 3. Уравнение Аррениуса

**Условие.** По зависимости константы скорости реакции от температуры (таблица 7, вариант «7 и 8») определить параметры уравнения Аррениуса

$$k = A \cdot e^{-E_a / (R \cdot T)},$$

где $k$ – константа скорости, с^−1^; $A$ – предэкспоненциальный множитель, с^−1^; $E_a$ – энергия активации, Дж/моль; $R = 8{,}314$ Дж/(моль∙К) – универсальная газовая постоянная; $T$ – абсолютная температура, К.

**Метод.** Температуры переведены в кельвины: $T = t + 273{,}15$. Логарифмирование даёт линейную зависимость

$$\ln k = \ln A - \frac{E_a}{R} \cdot \frac{1}{T},$$

параметры которой находятся линейным МНК (функция scipy.stats.linregress возвращает и стандартные ошибки коэффициентов): $E_a = -R \cdot b_1$, $A = e^{b_0}$, где $b_1$ – угловой коэффициент прямой, К; $b_0$ – свободный член. Доверительные интервалы рассчитаны с квантилем распределения Стьюдента $t_{0{,}975;\,7}$. Для анализа устойчивости оценок дополнительно выполнены расчёт без крайних точек (100 и 500 °C) и нелинейный МНК непосредственно по $k$ (curve_fit).

**Программа.**

```python
T3_t = np.arange(100.0, 501.0, 50.0)                                     # t, °C

T3_k = np.array([0.01, 0.10, 0.25, 0.78, 1.68, 2.98, 4.66, 8.94, 25.13])  # k, 1/с

def arrhenius(T, A, Ea):
    return A * np.exp(-Ea / (R * T))

def t1z3():
    TK = T3_t + 273.15                                   # перевод в кельвины
    # МНК для прямой ln k = b0 + b1/T
    lr = stats.linregress(1.0 / TK, np.log(T3_k))
    Ea, A = -lr.slope * R, np.exp(lr.intercept)
    tq = stats.t.ppf(0.975, len(TK) - 2)                 # квантиль Стьюдента, 95 %
    lnk_fit = lr.intercept + lr.slope / TK
    k_fit = np.exp(lnk_fit)
    lr_in = stats.linregress(1.0 / TK[1:-1], np.log(T3_k[1:-1]))   # без 100 и 500 °C
    # нелинейный МНК по k
    popt, _ = curve_fit(arrhenius, TK, T3_k, p0=[A, Ea], maxfev=20000)
    k_nl = arrhenius(TK, *popt)
    return dict(TK=TK, Ea=Ea, A=A, Ea_ci=tq * lr.stderr * R,
                lnA_ci=tq * lr.intercept_stderr, R2_ln=lr.rvalue ** 2,
                R2_k=r2_score(T3_k, k_fit), k_fit=k_fit,
                resid_ln=np.log(T3_k) - lnk_fit, ratio=T3_k / k_fit,
                Ea_in=-lr_in.slope * R, A_in=np.exp(lr_in.intercept),
                R2_in=lr_in.rvalue ** 2, A_nl=popt[0], Ea_nl=popt[1],
                R2_nl_k=r2_score(T3_k, k_nl),
                R2_nl_ln=r2_score(np.log(T3_k), np.log(k_nl)))
```

: Таблица 9 – Динамическая вязкость гексана, мПа∙с [1]

**Метод.** Модели

$$\mu(T) = \sum_{j=0}^{m} b_j \cdot T^{j}, \qquad m = 1, 2, 3,$$

где $\mu$ – динамическая вязкость, мПа∙с; $T$ – температура, К; $b_j$ – коэффициенты, мПа∙с/К^j^; $m$ – степень полинома. Коэффициенты находятся функцией numpy.polyfit. Кроме $R^{2}$ и $SSE$ рассчитаны: скорректированный $R^{2}_{\text{скор}}$; стандартное отклонение остатков $S = \sqrt{SSE / (n - m - 1)}$, мПа∙с; сумма квадратов ошибок перекрёстной проверки «без одной точки» $PRESS$, (мПа∙с)^2^ – каждая точка поочерёдно исключается, модель строится по остальным и прогнозирует исключённую; показатель чувствителен к переобучению. Значимость добавления кубического члена проверена F-критерием Фишера:

$$F = \frac{SSE_2 - SSE_3}{SSE_3 / (n - 4)},$$

где $SSE_2$, $SSE_3$ – остаточные суммы полиномов 2-й и 3-й степени, (мПа∙с)^2^; $n = 12$ – число точек. Для сопоставления построено также физически обоснованное уравнение Андраде $\ln \mu = A + B / T$ ($A$ – безразмерный коэффициент; $B$ – коэффициент, К).

**Программа.**

```python
# T, К и динамическая вязкость гексана μ, мПа·с
T4_T = np.array([250, 260, 270, 280, 290, 300, 310, 320, 330, 350, 370, 390.0])

T4_mu = np.array([0.497, 0.426, 0.397, 0.355, 0.320, 0.290, 0.264, 0.241, 0.221,
                  0.190, 0.158, 0.132])

def t1z4():
    n, models = len(T4_T), {}
    for deg in (1, 2, 3):
        p = np.polyfit(T4_T, T4_mu, deg)
        f = np.polyval(p, T4_T)
        s, r2, kp = sse(T4_mu, f), r2_score(T4_mu, f), deg + 1
        # перекрёстная проверка «без одной точки»
        press = 0.0
        for i in range(n):
            m = np.arange(n) != i
            p_i = np.polyfit(T4_T[m], T4_mu[m], deg)
            press += (T4_mu[i] - np.polyval(p_i, T4_T[i])) ** 2
        models[deg] = dict(p=p, fit=f, resid=T4_mu - f, SSE=s, R2=r2,
                           R2adj=1 - (1 - r2) * (n - 1) / (n - kp),
                           S=np.sqrt(s / (n - kp)), PRESS=press)
    # F-критерий значимости добавления члена степени 3 к полиному степени 2
    F = (models[2]["SSE"] - models[3]["SSE"]) / (models[3]["SSE"] / (n - 4))
    Fcrit = stats.f.ppf(0.95, 1, n - 4)
    # уравнение Андраде ln(mu) = A + B/T — физически обоснованная альтернатива
    B_, A_ = np.polyfit(1 / T4_T, np.log(T4_mu), 1)
    mu_and = np.exp(A_ + B_ / T4_T)
    # проверка подозрительной точки 260 К
    m = T4_T != 260
    B2, A2 = np.polyfit(1 / T4_T[m], np.log(T4_mu[m]), 1)
    p3m = np.polyfit(T4_T[m], T4_mu[m], 3)
    return dict(models=models, F=F, Fcrit=Fcrit, andrade=(A_, B_),
                R2_and=r2_score(T4_mu, mu_and), SSE_and=sse(T4_mu, mu_and),
                mu260_and=np.exp(A2 + B2 / 260), mu260_p3=np.polyval(p3m, 260))
```

## 2.1 Задание 1. Мольный объём аммиака

**Условие.** Определить мольный объём аммиака при $P = 80$ атм (8,1060 МПа) и $T = 450$ К по уравнениям идеального газа, Редлиха–Квонга и Соаве–Редлиха–Квонга; результат – в л/моль; сравнить и объяснить различия.

**Справочные данные.** Критические параметры и ацентрические факторы всех веществ темы 2 взяты из таблицы A2 справочника IFP [8] (таблица 11).

|:---|:---:|:---:|:---:|:---:|
| Аммиак NH~3~ | 405,6 | 111,3 | 11,278 | 0,250 |
| Диоксид углерода CO~2~ | 304,2 | 72,8 | 7,376 | 0,225 |

: Таблица 11 – Критические температура и давление, ацентрический фактор [8, A2, лист 1]

**Метод.** Уравнение идеального газа:

$$v = \frac{R \cdot T}{P},$$

где $v$ – мольный объём, м^3^/моль; $P$ – давление, Па; $T$ – температура, К; $R$ – универсальная газовая постоянная, Дж/(моль∙К).

Уравнения Редлиха–Квонга (RK) [9] и Соаве–Редлиха–Квонга (SRK) [10] имеют одинаковый вид

$$P = \frac{R \cdot T}{v - b} - \frac{a}{v \cdot (v + b)}, \qquad a = 0{,}42748 \cdot \frac{R^{2} \cdot T_c^{2}}{P_c} \cdot \alpha, \qquad b = 0{,}08664 \cdot \frac{R \cdot T_c}{P_c},$$

где $a$ – параметр притяжения молекул, Па∙м^6^/моль^2^; $b$ – собственный («исключённый») объём молекул, м^3^/моль; $T_c$ – критическая температура, К; $P_c$ – критическое давление, Па; $\alpha$ – безразмерная температурная функция. Уравнения различаются функцией $\alpha$:

$$\alpha_{\text{RK}} = T_r^{-0{,}5}, \qquad \alpha_{\text{SRK}} = \left( 1 + m \cdot \left( 1 - T_r^{0{,}5} \right) \right)^{2}, \qquad m = 0{,}480 + 1{,}574 \cdot \omega - 0{,}176 \cdot \omega^{2},$$

где $T_r = T / T_c$ – приведённая температура; $\omega$ – ацентрический фактор (учитывает несферичность молекулы); $m$ – безразмерный коэффициент Соаве.

Относительно $v$ уравнение кубическое [11]:

$$P \cdot v^{3} - R \cdot T \cdot v^{2} + \left( a - P \cdot b^{2} - R \cdot T \cdot b \right) \cdot v - a \cdot b = 0.$$

Все три корня находятся функцией numpy.roots. Физичный корень выбирается по правилам: он действительный и больше $b$ (объём не может быть меньше собственного объёма молекул), а для газовой фазы – наибольший из действительных (наименьший корень соответствует жидкости, средний – неустойчивому состоянию). Коэффициент сжимаемости $Z = P \cdot v / (R \cdot T)$ показывает отклонение от идеального газа, для которого $Z = 1$.

Для независимого контроля рассчитан $Z$ по обобщённой корреляции Ли–Кеслера [12]: $Z = Z^{(0)}(T_r, P_r) + \omega \cdot Z^{(1)}(T_r, P_r)$, где $P_r = P/P_c$ – приведённое давление; $Z^{(0)}$ – коэффициент сжимаемости простого вещества; $Z^{(1)}$ – поправка на ацентричность. Реализация проверена по таблицам справочника IFP (раздел I4 [8]): для шести табличных точек $Z^{(0)}$ воспроизводится с точностью ±0,0001.

**Программа.**

```python
# Tc, К; Pc, атм; ω — справочник Refining & Chemicals (IFP Training), табл. A2
CRIT = {
    "NH3": (405.6, 111.3, 0.250),
    "CO2": (304.2, 72.8, 0.225),
    "O2": (154.6, 49.8, 0.021),
    "N2": (126.2, 33.5, 0.040),
}

def eos_ab(Tc, Pc_atm, w, T, eos):
    """Параметры a (Па·м6/моль2) и b (м3/моль) уравнений RK и SRK."""
    Pc = Pc_atm * ATM
    Tr = T / Tc
    if eos == "RK":
        alpha = Tr ** -0.5
    else:                                            # SRK (Соаве)
        m = 0.480 + 1.574 * w - 0.176 * w ** 2
        alpha = (1 + m * (1 - Tr ** 0.5)) ** 2
    a = 0.42748 * R ** 2 * Tc ** 2 / Pc * alpha
    b = 0.08664 * R * Tc / Pc
    return a, b

def cubic_volume(a, b, T, P):
    """Корни P·v^3 − R·T·v^2 + (a − P·b^2 − R·T·b)·v − a·b = 0 и физичный корень."""
    roots = np.roots([P, -R * T, a - P * b ** 2 - R * T * b, -a * b])
    real = np.sort(roots[np.abs(roots.imag) < 1e-9 * np.abs(roots).max()].real)
    # объём больше собственного объёма молекул
    phys = real[real > b]
    # газ — наибольший действительный корень
    v = phys.max()
    return v, roots, real

# Константы обобщённого уравнения Ли–Кеслера (Lee, Kesler, AIChE J., 1975)
LK_SIMPLE = dict(b=(0.1181193, 0.265728, 0.154790, 0.030323),
                 c=(0.0236744, 0.0186984, 0.0, 0.042724),
                 d=(0.155488e-4, 0.623689e-4), beta=0.65392, gamma=0.060167)

LK_REF = dict(b=(0.2026579, 0.331511, 0.027655, 0.203488),
              c=(0.0313385, 0.0503618, 0.016901, 0.041577),
              d=(0.48736e-4, 0.0740336e-4), beta=1.226, gamma=0.03754)

def _lk_z(Tr, Pr, c):
    b1, b2, b3, b4 = c["b"]
    c1, c2, c3, c4 = c["c"]
    d1, d2 = c["d"]
    B = b1 - b2 / Tr - b3 / Tr ** 2 - b4 / Tr ** 3
    C = c1 - c2 / Tr + c3 / Tr ** 3
    D = d1 + d2 / Tr

    def f(Vr):
        g = c["gamma"] / Vr ** 2
        Z = (1 + B / Vr + C / Vr ** 2 + D / Vr ** 5
             + c4 / (Tr ** 3 * Vr ** 2) * (c["beta"] + g) * np.exp(-g))
        return Z - Pr * Vr / Tr
    grid = np.geomspace(3 * Tr / Pr, 0.05, 3000)     # от «газовых» объёмов к малым
    vals = np.array([f(v) for v in grid])
    i = np.nonzero(np.sign(vals[:-1]) != np.sign(vals[1:]))[0][0]
    Vr = brentq(f, grid[i + 1], grid[i])
    return Pr * Vr / Tr

def lee_kesler_z(Tr, Pr, w):
    """Z = Z0 + ω·Zcorr (простое вещество + поправка по н-октану, ωr = 0,3978)."""
    z0 = _lk_z(Tr, Pr, LK_SIMPLE)
    zr = _lk_z(Tr, Pr, LK_REF)
    return z0 + w / 0.3978 * (zr - z0), z0, (zr - z0) / 0.3978

def t2z1(T=450.0, P_atm=80.0):
    P = P_atm * ATM
    Tc, Pc, w = CRIT["NH3"]
    res = {"ИГ": dict(v=R * T / P)}
    for eos in ("RK", "SRK"):
        a, b = eos_ab(Tc, Pc, w, T, eos)
        v, roots, real = cubic_volume(a, b, T, P)
        res[eos] = dict(a=a, b=b, v=v, roots=roots, real=real)
    Z, z0, zc = lee_kesler_z(T / Tc, P_atm / Pc, w)
    res["LK"] = dict(v=Z * R * T / P, z0=z0, zcorr=zc)
    for d in res.values():
        d["Z"] = P * d["v"] / (R * T)
        d["v_L"] = d["v"] * 1000                      # м3/моль -> л/моль
    return dict(T=T, P=P, P_atm=P_atm, Tr=T / Tc, Pr=P_atm / Pc, res=res)
```

## 2.2 Задание 2. Мольный объём смеси CO~2~ – O~2~ – N~2~

**Условие.** Смесь содержит 25 % (мол.) диоксида углерода, остальное – кислород и азот в мольном соотношении 1 : 3. Рассчитать мольный объём смеси при $P = 150$ атм (15,1988 МПа) и $T = 420$ К по уравнениям идеального газа, RK и SRK (результат в л/моль), сравнить и ответить, является ли газ идеальным.

**Состав.** $y_{\mathrm{CO_2}} = 0{,}25$; $y_{\mathrm{O_2}} = 0{,}75 \cdot 1/4 = 0{,}1875$; $y_{\mathrm{N_2}} = 0{,}75 \cdot 3/4 = 0{,}5625$; сумма равна 1.

**Метод.** Параметры $a_i$, $b_i$ каждого компонента рассчитываются по формулам задания 2.1 (для SRK – со своими $\alpha_i$ и $m_i$), критические параметры – по таблице 11. Параметры смеси находятся по правилам смешения [2, 11]:

$$a = \left( \sum_{i=1}^{N} y_i \cdot \sqrt{a_i} \right)^{2}, \qquad b = \sum_{i=1}^{N} y_i \cdot b_i,$$

где $y_i$ – мольная доля $i$-го компонента; $N = 3$ – число компонентов; $a$, Па∙м^6^/моль^2^, и $b$, м^3^/моль, – параметры смеси. Правило для $a$ эквивалентно комбинированию $a_{ij} = \sqrt{a_i \cdot a_j}$ (правило Лоренца–Бертло без поправок на бинарное взаимодействие). Далее решается то же кубическое уравнение, что и для чистого вещества. Для контроля по Ли–Кеслеру смесь заменена псевдочистым веществом с псевдокритическими параметрами по правилу Кея: $T_{pc} = \sum y_i \cdot T_{c,i} = 176{,}02$ К, $P_{pc} = \sum y_i \cdot P_{c,i} = 46{,}38$ атм, $\omega = \sum y_i \cdot \omega_i = 0{,}0827$.

**Программа.**

```python
def t2z2(T=420.0, P_atm=150.0):
    P = P_atm * ATM
    names = ["CO2", "O2", "N2"]
    # 25 % CO2, O2 : N2 = 1 : 3
    y = np.array([0.25, 0.75 * 1 / 4, 0.75 * 3 / 4])
    res = {"ИГ": dict(v=R * T / P)}
    for eos in ("RK", "SRK"):
        ab = np.array([eos_ab(*CRIT[n], T, eos) for n in names])
        ai, bi = ab[:, 0], ab[:, 1]
        # правило смешения для a
        a = np.sum(y * np.sqrt(ai)) ** 2
        # правило смешения для b
        b = np.sum(y * bi)
        v, roots, real = cubic_volume(a, b, T, P)
        res[eos] = dict(ai=ai, bi=bi, a=a, b=b, v=v, roots=roots, real=real)
    Tpc = sum(yi * CRIT[n][0] for yi, n in zip(y, names))      # правило Кея
    Ppc = sum(yi * CRIT[n][1] for yi, n in zip(y, names))
    wm = sum(yi * CRIT[n][2] for yi, n in zip(y, names))
    Z, z0, zc = lee_kesler_z(T / Tpc, P_atm / Ppc, wm)
    res["LK"] = dict(v=Z * R * T / P, z0=z0, zcorr=zc)
    for d in res.values():
        d["Z"] = P * d["v"] / (R * T)
        d["v_L"] = d["v"] * 1000
    return dict(T=T, P=P, P_atm=P_atm, y=y, names=names, Tpc=Tpc, Ppc=Ppc, w=wm,
                Tpr=T / Tpc, Ppr=P_atm / Ppc, res=res)
```

Это согласуется с тем, что азот при 420 К находится заметно выше своей температуры Бойля (около 327 К), а кислород – вблизи неё (около 406 К); выше температуры Бойля $Z > 1$ при любых давлениях. Контроль по Ли–Кеслеру даёт $Z = 1{,}0184$ – между RK и SRK.

Ответ на вопрос «является ли газ идеальным?»: по совокупному коэффициенту сжимаемости ($Z$ от 0,9943 до 1,0333) отклонение мольного объёма от идеального газа не превышает 3,3 %, то есть для оценочных расчётов объёма уравнение идеального газа здесь применимо. Строго идеальным газ не является: близость $Z$ к единице – результат взаимной компенсации притяжения и отталкивания при 150 атм, а не отсутствия межмолекулярных взаимодействий. При другом давлении или для расчёта других свойств (фугитивность, энтальпия) отклонения будут существенны.

Газ близок к идеальному по объёму (отклонение до 3,3 %), но не идеален по сути. ## 3.1 Задание 1. Температуры начала и конца кипения

**Условие.** Рассчитать температуры начала и конца кипения (°C) идеальной смеси 15 % метана, 30 % этана, 35 % пропана и 20 % н-пентана (мольные доли) при абсолютном давлении 14 атм (1,4185 МПа).

**Справочные данные.** Константы фазового равновесия рассчитываются по корреляции McWilliams [13], которая аппроксимирует номограммы ДеПристера для лёгких углеводородов:

$$\ln K_i = -\frac{A_i}{T^{2}} + B_i - C_i \cdot \ln P + \frac{D_i}{P^{2}} \quad (1), \qquad \ln K_i = -\frac{A_i}{T^{2}} + B_i - C_i \cdot \ln P + \frac{D_i}{P} \quad (2),$$

где $K_i = y_i / x_i$ – константа фазового равновесия $i$-го компонента (безразмерна); $T$ – температура, °R; $P$ – давление, psia; $A_i$ – коэффициент, °R^2^; $B_i$, $C_i$ – безразмерные коэффициенты; $D_i$ – коэффициент, psia^2^ (форма 1) или psia (форма 2). Коэффициенты – из задания (таблица 15).

Пересчёт единиц: $T_{°\text{R}} = 1{,}8 \cdot T_{\text{К}}$; $P_{\text{psia}} = P_{\text{Па}} / 6894{,}757$. При 14 атм давление равно 205,74 psia.

**Метод.** Для идеальной смеси $K_i$ не зависит от состава. Температура начала кипения $T_{\text{нк}}$ (появление первого пузырька пара из жидкости состава $x_i = z_i$) удовлетворяет условию $\sum y_i = 1$, а температура конца кипения $T_{\text{кк}}$ (исчезновение последней капли жидкости, пар состава $y_i = z_i$) – условию $\sum x_i = 1$ [11]. Для многокомпонентной смеси сходимость лучше в логарифмической форме:

$$\ln \left( \sum_{i=1}^{N} K_i(T, P) \cdot x_i \right) = 0, \qquad \ln \left( \sum_{i=1}^{N} \frac{y_i}{K_i(T, P)} \right) = 0,$$

где $x_i$, $y_i$ – мольные доли компонентов в жидкости и паре; $z_i$ – мольная доля в исходной смеси; $N$ – число компонентов. Каждое уравнение – нелинейное с одной неизвестной $T$; функции монотонны по $T$, поэтому после графической локализации (рисунок 8) корень уточняется методом Брента (scipy.optimize.brentq) на интервале, где функция меняет знак.

**Программа.**

```python
# A, B, C, D, форма: ln K = −A/T^2 + B − C·ln P + D/P^2 (1) или + D/P (2);
# T в °R, P в psia
MCW = {
    "CH4": (292860.0, 8.2445, 0.8951, 59.8465, 1),
    "C2H6": (687248.2, 7.90694, 0.866, 49.02654, 1),
    "C3H8": (970688.6, 7.15059, 0.76984, 6.90224, 2),
    "i-C4H10": (1166846.0, 7.72668, 0.92213, 0.0, 1),
    "n-C4H10": (1280557.0, 7.94986, 0.96455, 0.0, 1),
    "n-C5H12": (1524891.0, 7.33129, 0.89143, 0.0, 1),
}

def k_mcw(names, T_K, P_Pa):
    """Константы фазового равновесия McWilliams; вход в К и Па, внутри °R и psia."""
    TR, Pp = 1.8 * T_K, P_Pa / PSI
    K = []
    for n in names:
        A, B, C, D, form = MCW[n]
        last = D / Pp ** 2 if form == 1 else D / Pp
        K.append(np.exp(-A / TR ** 2 + B - C * np.log(Pp) + last))
    return np.array(K)

def bubble_T(x, names, P):
    """Температура начала кипения: ln(Σ K_i·x_i) = 0."""
    f = lambda T: np.log(np.sum(k_mcw(names, T, P) * x))
    return brentq(f, 120.0, 700.0, xtol=1e-12)

def dew_T(y, names, P):
    """Температура конца кипения (начала конденсации): ln(Σ y_i/K_i) = 0."""
    f = lambda T: np.log(np.sum(y / k_mcw(names, T, P)))
    return brentq(f, 120.0, 900.0, xtol=1e-12)

T3Z1_NAMES = ["CH4", "C2H6", "C3H8", "n-C5H12"]

T3Z1_Z = np.array([0.15, 0.30, 0.35, 0.20])

def t3z1(P_atm=14.0):
    P = P_atm * ATM
    Tb, Td = bubble_T(T3Z1_Z, T3Z1_NAMES, P), dew_T(T3Z1_Z, T3Z1_NAMES, P)
    Kb, Kd = k_mcw(T3Z1_NAMES, Tb, P), k_mcw(T3Z1_NAMES, Td, P)
    return dict(P=P, P_psia=P / PSI, Tb=Tb, Td=Td, tb=Tb - 273.15, td=Td - 273.15,
                Kb=Kb, Kd=Kd, y_bubble=Kb * T3Z1_Z, x_dew=T3Z1_Z / Kd,
                res_b=np.sum(Kb * T3Z1_Z) - 1, res_d=np.sum(T3Z1_Z / Kd) - 1)
```

## 3.2 Задание 2. Расчёт сепарационного блока

**Условие.** Сырьё (природный газ с тяжёлыми углеводородами, состав – в таблице 17) последовательно проходит три сепаратора (рисунок 9): газ сепаратора С1 поступает в С2, газ С2 – в С3; из каждого сепаратора отводится жидкая фаза. Базовые условия: С1 – $P_1 = 9{,}8$ МПа, $t_1 = 40{,}8$ °C; С2 – $P_2 = 8{,}7$ МПа, $t_2 = 12{,}8$ °C; С3 – $P_3 = 8{,}7$ МПа, $t_3 = -40{,}8$ °C. Рассчитать составы газовых и жидких потоков, затем (вариант 8) исследовать влияние давления во втором сепараторе и выбрать эффективный режим разделения. Константы равновесия – по корреляции McWilliams (таблица 15; компонент «C~4~» задания – н-бутан, «C~5~» – н-пентан).

![Рисунок 9 – Схема сепарационного блока и мольные потоки в базовом режиме (на 1 моль сырья)](fig/t3z2_scheme.png){width=16cm}

**Метод.** Каждый сепаратор – аппарат однократного испарения при заданных $P$ и $T$. Доля отгона $e = V / F$ (мольная доля питания, перешедшая в газ) находится из уравнения Рачфорда–Райса [14]

$$f(e) = \sum_{i=1}^{N} \frac{z_i \cdot (K_i - 1)}{1 + e \cdot (K_i - 1)} = 0,$$

после чего составы фаз и потоки:

$$x_i = \frac{z_i}{1 + e \cdot (K_i - 1)}, \qquad y_i = K_i \cdot x_i, \qquad V = e \cdot F, \qquad L = (1 - e) \cdot F,$$

где $z_i$ – мольная доля компонента в питании сепаратора; $x_i$, $y_i$ – мольные доли в жидкости и газе; $F$, $V$, $L$ – мольные расходы питания, газа и жидкости, моль на 1 моль сырья блока; $e$ – доля отгона, моль/моль. Функция $f(e)$ монотонно убывает между асимптотами $e_{\min} = 1/(1 - K_{\max})$ и $e_{\max} = 1/(1 - K_{\min})$, поэтому корень на этом интервале единственный и надёжно находится методом Брента. Если найденный корень $e < 0$ (равносильно $\sum z_i \cdot K_i \le 1$), питание – недогретая жидкость; если $e > 1$ ($\sum z_i / K_i \le 1$) – перегретый газ. В обоих случаях сепаратор работает вхолостую: поток проходит его однофазным, программа присваивает $e = 0$ или $e = 1$ и сообщает формальное значение корня.

Показатели работы блока: выход газа сепаратора С3 $V_3$; содержание углеводородов C~3+~ в этом газе; извлечение компонента $i$ в суммарную жидкость

$$\varepsilon_i = \frac{\sum_{j=1}^{3} L_j \cdot x_{i,j}}{F \cdot z_i},$$

где $L_j$ – расход жидкости из $j$-го сепаратора, моль; $x_{i,j}$ – мольная доля компонента в ней; и показатель чёткости разделения $\text{Ч} = \varepsilon_{\mathrm{C_3H_8}} - \varepsilon_{\mathrm{CH_4}}$ (доля пропана сырья, ушедшая в жидкость, минус доля метана, ушедшая в жидкость; при идеальном разделении $\text{Ч} = 1$).

**Программа.**

```python
SEP_NAMES = ["CH4", "C2H6", "C3H8", "i-C4H10", "n-C4H10", "n-C5H12"]

SEP_Z = np.array([0.72211, 0.03608, 0.22363, 0.00646, 0.00466, 0.00706])

SEP_BASE = [(9.8 * MPA, 40.8 + 273.15),     # (P, Па; T, К) для С1, С2, С3
            (8.7 * MPA, 12.8 + 273.15),
            (8.7 * MPA, -40.8 + 273.15)]

def rachford_rice(z, K):
    """Решение Σ z_i·(K_i − 1)/(1 + e·(K_i − 1)) = 0 на интервале между асимптотами.
    Возвращает (e, e_формальное, состояние); e вне [0; 1] — однофазная смесь."""
    f = lambda e: np.sum(z * (K - 1) / (1 + e * (K - 1)))
    if K.max() <= 1:
        return 0.0, -np.inf, "жидкость"
    if K.min() >= 1:
        return 1.0, np.inf, "газ"
    lo, hi = 1 / (1 - K.max()), 1 / (1 - K.min())   # асимптоты функции РР
    eps = 1e-12 * (hi - lo)
    e_formal = brentq(f, lo + eps, hi - eps, xtol=1e-15)
    # Σ z·K ≤ 1: переохлаждённая жидкость
    if e_formal <= 0:
        return 0.0, e_formal, "жидкость"
    if e_formal >= 1:                                 # Σ z/K ≤ 1: перегретый газ
        return 1.0, e_formal, "газ"
    return e_formal, e_formal, "двухфазная"

def flash(z, T, P, names=SEP_NAMES):
    K = k_mcw(names, T, P)
    e, e_formal, state = rachford_rice(z, K)
    if state == "двухфазная":
        x = z / (1 + e * (K - 1))
        y = K * x
    elif state == "газ":
        x, y = np.full_like(z, np.nan), z.copy()
    else:
        x, y = z.copy(), np.full_like(z, np.nan)
    return dict(K=K, e=e, e_formal=e_formal, state=state, x=x, y=y,
                rr=(np.sum(z * (K - 1) / (1 + e * (K - 1)))
                    if state == "двухфазная" else np.nan))

def separator_train(conds, z=SEP_Z, F=1.0):
    """Газ каждого сепаратора — питание следующего. F — моль сырья (на 1 моль)."""
    out, feed = [], z
    for (P, T) in conds:
        s = flash(feed, T, P)
        s.update(F=F, z=feed, P=P, T=T, V=F * s["e"], L=F * (1 - s["e"]))
        out.append(s)
        F, feed = s["V"], s["y"]
    return out

def train_summary(tr, z=SEP_Z):
    """Показатели блока: выход и состав газа С3, извлечение C3H8, потери CH4."""
    # покомпонентно, моль/моль сырья
    liq = sum(s["L"] * np.nan_to_num(s["x"]) for s in tr)
    # если С3 весь в жидкости — газа нет
    gas = tr[-1]["V"] * np.nan_to_num(tr[-1]["y"])
    rec = liq / z
    return dict(e=[s["e"] for s in tr], states=[s["state"] for s in tr],
                V_out=tr[-1]["V"], y_out=tr[-1]["y"],
                yC3plus=float(np.sum(tr[-1]["y"][2:])),
                rec_C3=rec[2], loss_CH4=rec[0],
                rec_C4plus=float(np.sum(liq[3:]) / np.sum(z[3:])),
                sharp=rec[2] - rec[0], closure=float(np.max(np.abs(liq + gas - z))))

def t3z2_base():
    tr = separator_train(SEP_BASE)
    return dict(train=tr, summary=train_summary(tr))

def p_dew_at(y, T, names=SEP_NAMES):
    """Давление начала конденсации газа состава y при температуре T: Σ y_i/K_i = 1."""
    return brentq(lambda P: np.sum(y / k_mcw(names, T, P)) - 1, 0.2 * MPA, 30 * MPA)

def t3z2_study(P2_grid=None, rule="P3=P2"):
    """Влияние давления во втором сепараторе. Газ идёт С2 -> С3 без компрессора,
    поэтому P3 ≤ P2; основное правило P3 = P2 (как в базе); P2 ≤ P1 = 9,8 МПа."""
    if P2_grid is None:
        P2_grid = np.round(np.arange(4.0, 9.8 + 1e-9, 0.1), 2)
    rows = []
    for P2 in P2_grid:
        P3 = P2 if rule == "P3=P2" else min(P2, 8.7)
        conds = [SEP_BASE[0], (P2 * MPA, SEP_BASE[1][1]), (P3 * MPA, SEP_BASE[2][1])]
        tr = separator_train(conds)
        s = train_summary(tr)
        s.update(P2=P2, P3=P3, e_formal=[t["e_formal"] for t in tr])
        rows.append(s)
    # газ С1 (не зависит от P2)
    y1 = separator_train(SEP_BASE[:1])[0]["y"]
    # ниже — С2 однофазен (газ)
    P2_dew = p_dew_at(y1, SEP_BASE[1][1]) / MPA
    return dict(rows=rows, P2_dew=P2_dew, rule=rule)
```

## 4.1 Задание 1. Синтез аммиака

**Условие.** Найти мольные расходы веществ на выходе из равновесного реактора синтеза аммиака

$$\mathrm{\tfrac{1}{2} N_2 + \tfrac{3}{2} H_2 \rightleftarrows NH_3},$$

если на вход поступает смесь азот : водород : аммиак = 1,1 : 3 : 0,2 (моль); $K_p = 0{,}05$ атм^−1^, $T = 589$ К, $P = 220$ атм.

**Метод.** Вводится степень полноты реакции $\xi$, моль (количество образовавшегося NH~3~). Количества веществ $n_i = n_{i,0} + \nu_i \cdot \xi$, где $n_{i,0}$ – начальное количество, моль; $\nu_i$ – стехиометрический коэффициент (для N~2~, H~2~ и NH~3~ соответственно $-1/2$, $-3/2$ и $+1$). Для идеальной газовой смеси [11]

$$K_p = \frac{y_{\mathrm{NH_3}}}{y_{\mathrm{N_2}}^{0{,}5} \cdot y_{\mathrm{H_2}}^{1{,}5}} \cdot P^{-1}, \qquad y_i = \frac{n_i}{\sum n_i},$$

где $K_p$ – константа равновесия, атм^−1^; $y_i$ – равновесная мольная доля; $P$ – общее давление, атм ($\Delta \nu = -1$). Подстановка $n_i(\xi)$ даёт нелинейное уравнение с одной неизвестной

$$f(\xi) = \frac{(0{,}2 + \xi) \cdot (4{,}3 - \xi)}{(1{,}1 - 0{,}5 \cdot \xi)^{0{,}5} \cdot (3 - 1{,}5 \cdot \xi)^{1{,}5}} \cdot \frac{1}{P} - K_p = 0.$$

Физически допустимый интервал: $-0{,}2 < \xi < 2$ (аммиак не может разложиться в большем количестве, чем его было; водород исчерпывается при $\xi = 2$). На этом интервале функция монотонна (проверено подсчётом смен знака на сетке из 2000 точек – корень один); корень уточняется методом Брента.

**Программа.**

```python
def t4z1(Kp=0.05, P_atm=220.0, n0=(1.1, 3.0, 0.2)):
    n0 = np.array(n0)                       # N2, H2, NH3, моль
    nu = np.array([-0.5, -1.5, 1.0])        # стехиометрические коэффициенты

    def f(xi):                              # xi — степень полноты реакции, моль
        n = n0 + nu * xi
        y = n / n.sum()
        return y[2] / (y[0] ** 0.5 * y[1] ** 1.5) / P_atm - Kp
    xi_max = min(-n0[0] / nu[0], -n0[1] / nu[1])        # до исчерпания H2 (2 моль)
    xi_min = -n0[2]                                     # до исчезновения NH3
    grid = np.linspace(xi_min + 1e-9, xi_max - 1e-9, 2001)
    sgn = np.sign([f(g) for g in grid])
    roots = int(np.sum(sgn[:-1] != sgn[1:]))             # число смен знака на сетке
    xi = brentq(f, xi_min + 1e-12, xi_max - 1e-12, xtol=1e-15)
    n = n0 + nu * xi
    return dict(n0=n0, n=n, y=n / n.sum(), xi=xi, residual=f(xi), n_roots=roots,
                conv_N2=0.5 * xi / n0[0], conv_H2=1.5 * xi / n0[1], f=f,
                xi_lim=(xi_min, xi_max),
                Kp=Kp, P_atm=P_atm)
```

**Метод.** Стандартная энергия Гиббса реакции и константа равновесия:

$$\Delta G^{\circ}_{r}(T) = \sum_i \nu_i \cdot \Delta G^{\circ}_{f,i}(T), \qquad K = \exp \left( -\frac{\Delta G^{\circ}_{r}}{R \cdot T} \right),$$

где $\Delta G^{\circ}_{r}$ – стандартная энергия Гиббса реакции, Дж/моль (1 кал = 4,184 Дж); $\nu_i$ – стехиометрические коэффициенты (продукты – плюс, исходные вещества – минус); $K$ – безразмерная константа равновесия, численно равная $K_p$ в атм^Δν^ при стандартном давлении 1 атм.

Справочник приводит данные только до 1000 К, поэтому значение при 1100 К получено экстраполяцией двумя способами – линейно по температуре (по точкам 800 и 1000 К) и через энтальпию и энтропию реакции:

$$\Delta G^{\circ}_{r}(1100) = \Delta G^{\circ}_{r}(1000) + \frac{\Delta G^{\circ}_{r}(1000) - \Delta G^{\circ}_{r}(800)}{200} \cdot 100,$$

$$\Delta G^{\circ}_{r}(T) = \Delta H^{\circ}_{r}(1000) - T \cdot \Delta S^{\circ}_{r}(1000), \qquad \Delta S^{\circ}_{r}(1000) = \frac{\Delta H^{\circ}_{r}(1000) - \Delta G^{\circ}_{r}(1000)}{1000},$$

где $\Delta H^{\circ}_{r}$ – стандартная энтальпия реакции, кал/моль; $\Delta S^{\circ}_{r}$ – стандартная энтропия реакции, кал/(моль∙К). Второй способ предполагает постоянство $\Delta H^{\circ}_{r}$ и $\Delta S^{\circ}_{r}$ выше 1000 К; это оправдано, так как $\Delta H^{\circ}_{r}$ от 800 до 1000 К меняется лишь на 0,6 %.

Для 1 моль этана при превращении $x$ моль: C~2~H~6~ $1 - x$, C~2~H~4~ $x$, H~2~ $x$, всего $1 + x$ моль. Тогда

$$K_p = \frac{y_{\mathrm{C_2H_4}} \cdot y_{\mathrm{H_2}}}{y_{\mathrm{C_2H_6}}} \cdot P = \frac{x^{2}}{(1 - x) \cdot (1 + x)} \cdot P, \qquad x = \sqrt{\frac{K_p}{K_p + P}},$$

где $x$ – степень превращения этана; $P$ – давление, атм.

```python
def k_extrap(T, prod, reac):
    """K реакции reac -> prod + H2 при T > 1000 К двумя способами экстраполяции."""
    dG = DGF[prod] - DGF[reac]                     # ΔG°r(T) по табличным точкам
    dH = DHF[prod] - DHF[reac]

    dG_lin = dG[-1] + (dG[-1] - dG[-2]) / 200.0 * (T - 1000.0)
    # (2) ΔH°r и ΔS°r при 1000 К считаем постоянными: ΔG = ΔH − T·ΔS
    dS = (dH[-1] - dG[-1]) / 1000.0

    K_lin = np.exp(-dG_lin * CAL / (R * T))
    K_hs = np.exp(-dG_hs * CAL / (R * T))
    return dict(dG=dG, dH=dH, dS=dS, dG_lin=dG_lin, dG_hs=dG_hs,
                K_lin=K_lin, K_hs=K_hs)

def ethane_equilibrium(K, P_atm=1.0):
    """Kp = x^2/((1 − x)(1 + x))·P -> x = sqrt(K/(K + P)) для 1 моль этана."""
    x = np.sqrt(K / (K + P_atm))
    n = np.array([1 - x, x, x])                    # C2H6, C2H4, H2
    return x, n, n / n.sum()

def t4z2a(T=1100.0, P_atm=1.0):

    K = ke["K_lin"]                                # основной вариант

    resid = y[1] * y[2] / y[0] * P_atm - K
    sens = {}
    for name, Kv in (("lin", ke["K_lin"]), ("hs", ke["K_hs"]), ("Finlayson", 1.76)):
        sens[name] = (Kv,) + ethane_equilibrium(Kv, P_atm)[0:1]
    dxdK = 1 / (2 * x) * P_atm / (K + P_atm) ** 2
    k1367 = k_extrap(1367.0, "C2H4", "C2H6")       # контроль заданных Kp при 1367 К

    K1000 = np.exp(-ke["dG"][-1] * CAL / (R * 1000.0))
    return dict(T=T, ke=ke, K=K, x=x, n=n, y=y, residual=resid, sens=sens, dxdK=dxdK,
                K1000=K1000, K1_1367=(k1367["K_lin"], k1367["K_hs"]),
                K2_1367=(k2_1367["K_lin"], k2_1367["K_hs"]), dG2=k2_1367["dG"])
```

### 4.2.2 Две реакции, 1367 К (пункт б)

**Условие.** Добавляется вторая реакция

$$\mathrm{C_2H_4 \rightleftarrows C_2H_2 + H_2},$$

температура повышается до 1367 К; $K_{p1} = 37{,}6$ атм, $K_{p2} = 0{,}769$ атм. Давление 1 атм (в условии не изменяется).

**Метод.** Для каждого стехиометрического уравнения вводится своя неизвестная: $x_1$ – моль прореагировавшего этана, $x_2$ – моль этилена, превратившегося в ацетилен. Количества на 1 моль этана: C~2~H~6~ $1 - x_1$; C~2~H~4~ $x_1 - x_2$; H~2~ $x_1 + x_2$; C~2~H~2~ $x_2$; всего $1 + x_1 + x_2$. Система двух нелинейных уравнений:

$$\frac{(x_1 - x_2) \cdot (x_1 + x_2)}{(1 - x_1) \cdot (1 + x_1 + x_2)} \cdot P = K_{p1}, \qquad \frac{x_2 \cdot (x_1 + x_2)}{(x_1 - x_2) \cdot (1 + x_1 + x_2)} \cdot P = K_{p2}.$$

Физическая область: $0 < x_2 < x_1 < 1$ (все количества положительны). Система решена функцией scipy.optimize.least_squares с ограничениями на переменные. Для сравнения показано, что fsolve без ограничений из того же начального приближения (0,9; 0,3) уходит в нефизичную область ($x_1 = −73{,}0$, $x_2 = −2859{,}9$) и не сходится. Единственность физичного решения проверена перебором 120 начальных приближений внутри области: все сошедшиеся решения совпадают.

**Программа.**

```python
def t4z2b(K1=37.6, K2=0.769, P_atm=1.0):
    # v = (x1, x2): x1 — этана прореагировало, x2 — этилена
    def F(v):
        x1, x2 = v
        nt = 1 + x1 + x2
        return [(x1 - x2) * (x1 + x2) / ((1 - x1) * nt) * P_atm - K1,
                x2 * (x1 + x2) / ((x1 - x2) * nt) * P_atm - K2]
    lo, hi = [1e-12, 1e-12], [1 - 1e-12, 1 - 1e-12]          # 0 < x1, x2 < 1
    sol = least_squares(F, [0.9, 0.3], bounds=(lo, hi),
                        xtol=1e-15, ftol=1e-15, gtol=1e-15)
    x1, x2 = sol.x
    # без ограничений — для сравнения
    raw = fsolve(F, [0.9, 0.3], full_output=True)
    # перебор начальных приближений
    found = set()
    for a in np.linspace(0.05, 0.99, 15):
        for b in np.linspace(0.01, 0.98, 15):
            if b < a:
                s, info, ier, msg = fsolve(F, [a, b], full_output=True)
                if ier == 1 and 0 < s[1] < s[0] < 1 and max(map(abs, F(s))) < 1e-9:
                    found.add((round(float(s[0]), 7), round(float(s[1]), 7)))
    n = np.array([1 - x1, x1 - x2, x1 + x2, x2])        # C2H6, C2H4, H2, C2H2
    return dict(x1=x1, x2=x2, n=n, y=n / n.sum(), residual=np.array(F(sol.x)),
                fsolve_raw=raw[0], fsolve_raw_res=np.array(F(raw[0])),
                unique=sorted(found))
```

## 5.1 Задание 1. Схема разделения ксилол – стирол – толуол – бензол

**Условие.** Смесь (1000 моль/ч) разделяется в трёх колоннах (рисунок 14): колонна 1 делит сырьё F на дистиллят D и кубовый остаток B, колонна 2 делит D на D~1~ и B~1~, колонна 3 делит B на D~2~ и B~2~. Составы потоков F, D~1~, B~1~, D~2~, B~2~ заданы (таблица 28). Найти расходы и составы всех потоков.

**Метод.** Покомпонентные балансы всей схемы (D и B – внутренние потоки):

$$F \cdot x_{F,i} = D_1 \cdot x_{D_1,i} + B_1 \cdot x_{B_1,i} + D_2 \cdot x_{D_2,i} + B_2 \cdot x_{B_2,i}, \qquad i = 1, \ldots, 4,$$

где $F$, $D_1$, $B_1$, $D_2$, $B_2$ – мольные расходы потоков, моль/ч; $x_{j,i}$ – мольная доля $i$-го компонента (ксилол, стирол, толуол, бензол) в потоке $j$. Это система четырёх линейных уравнений с четырьмя неизвестными $\mathbf{A} \cdot \mathbf{X} = \mathbf{b}$, где столбцы матрицы $\mathbf{A}$ – составы продуктов, $\mathbf{b} = F \cdot \mathbf{x}_F$ [11]. Решение – numpy.linalg.solve (метод Гаусса с выбором ведущего элемента, без явного обращения матрицы). Затем из балансов колонн 2 и 3:

$$D = D_1 + B_1, \qquad x_{D,i} = \frac{D_1 \cdot x_{D_1,i} + B_1 \cdot x_{B_1,i}}{D}, \qquad B = D_2 + B_2, \qquad x_{B,i} = \frac{D_2 \cdot x_{D_2,i} + B_2 \cdot x_{B_2,i}}{B}.$$

Проверяются неотрицательность расходов, суммы долей, покомпонентные балансы каждой колонны и обусловленность матрицы.

**Программа.**

```python
T5_COMP = ["Ксилол", "Стирол", "Толуол", "Бензол"]

    b = F * T5_X["F"]
    D1, B1, D2, B2 = np.linalg.solve(A, b)
    D, B = D1 + B1, D2 + B2                                   # балансы колонн 2 и 3
    xD = (D1 * T5_X["D1"] + B1 * T5_X["B1"]) / D
    xB = (D2 * T5_X["D2"] + B2 * T5_X["B2"]) / B
    flows = {"F": F, "D": D, "B": B, "D1": D1, "B1": B1, "D2": D2, "B2": B2}
    comp = {"F": T5_X["F"], "D": xD, "B": xB, "D1": T5_X["D1"], "B1": T5_X["B1"],
            "D2": T5_X["D2"], "B2": T5_X["B2"]}
    # невязки покомпонентных балансов каждой колонны
    res = np.concatenate([F * comp["F"] - D * xD - B * xB,
                          D * xD - D1 * comp["D1"] - B1 * comp["B1"],
                          B * xB - D2 * comp["D2"] - B2 * comp["B2"]])
    # чувствительность к погрешности составов: отклонения ±d (абс.) с нормировкой
    mc = {}
    for d in (0.001, 0.0025):
        rng = np.random.default_rng(8)
        sims = []
        for _ in range(5000):
            Ap = np.clip(A + rng.uniform(-d, d, A.shape), 0, None)
            Ap /= Ap.sum(axis=0)
            sims.append(np.linalg.solve(Ap, b))
        sims = np.array(sims)
        mc[d] = dict(p5=np.percentile(sims, 5, axis=0),
                     p95=np.percentile(sims, 95, axis=0),
                     neg=float(np.mean((sims < 0).any(axis=1))))
    return dict(A=A, b=b, flows=flows, comp=comp, residual=res,
                cond=np.linalg.cond(A), det=np.linalg.det(A),
                sv=np.linalg.svd(A, compute_uv=False), mc=mc)
```

## 5.2 Задание 2. Процесс Toray: бензол из толуола с рециклом

**Условие.** Свежий толуол (поток 1, 100 моль/ч) смешивается с рециклом (поток 7) в смесителе M и поступает (поток 2) в реактор R, где протекает диспропорционирование

$$\mathrm{2 C_7H_8 \rightleftarrows C_6H_6 + C_8H_{10}}$$

с конверсией толуола за проход 58 %. Поток 3 разделяется в S~1~: поток 4 (бензол) содержит 99,5 % бензола, 0,1 % толуола и 0 % ксилола потока 3; остальное – поток 5. В S~2~ поток 7 (рецикл) содержит весь бензол, 99,5 % толуола и 0,1 % ксилола потока 5; остальное – поток 6 (ксилол). Рассчитать материальный баланс и конверсию толуола в ксилол. В условии задания опечатка «кислол» – имеется в виду ксилол.

**Метод.** Мольные расходы компонентов (толуол Т, бензол Б, ксилол К) образуют вектор $\mathbf{n}_j = (n_{\text{Т}}, n_{\text{Б}}, n_{\text{К}})_j$, моль/ч. Уравнения блоков [11]:

- смеситель: $\mathbf{n}_2 = \mathbf{n}_1 + \mathbf{n}_7$;
- реактор (прореагировало $\alpha \cdot n_{\text{Т},2}$ толуола, $\alpha = 0{,}58$; образовалось по $\alpha \cdot n_{\text{Т},2} / 2$ бензола и ксилола): $n_{\text{Т},3} = (1 - \alpha) \cdot n_{\text{Т},2}$, $n_{\text{Б},3} = n_{\text{Б},2} + \alpha \cdot n_{\text{Т},2}/2$, $n_{\text{К},3} = n_{\text{К},2} + \alpha \cdot n_{\text{Т},2}/2$, то есть $\mathbf{n}_3 = \mathbf{M} \cdot \mathbf{n}_2$;
- разделители: $n_{i,4} = f_{i}^{(4)} \cdot n_{i,3}$, $\mathbf{n}_5 = \mathbf{n}_3 - \mathbf{n}_4$; $n_{i,7} = f_{i}^{(7)} \cdot n_{i,5}$, $\mathbf{n}_6 = \mathbf{n}_5 - \mathbf{n}_7$, где $f^{(4)} = (0{,}001;\ 0{,}995;\ 0)$ и $f^{(7)} = (0{,}995;\ 1;\ 0{,}001)$ – доли компонентов, направляемые в потоки 4 и 7.

Из-за рецикла расход потока 2 заранее неизвестен. Разрываем рецикл по потоку 7: все блоки линейны, поэтому $\mathbf{n}_7 = \mathbf{G} \cdot (\mathbf{n}_1 + \mathbf{n}_7)$, где $\mathbf{G} = \text{diag}(f^{(7)}) \cdot \text{diag}(1 - f^{(4)}) \cdot \mathbf{M}$. Задача решена двумя способами: (а) методом простой итерации по разрываемому потоку, начиная с $\mathbf{n}_7 = 0$ (как в практическом занятии); (б) прямым решением линейной системы $(\mathbf{E} - \mathbf{G}) \cdot \mathbf{n}_7 = \mathbf{G} \cdot \mathbf{n}_1$, где $\mathbf{E}$ – единичная матрица. Для толуола решение получается и аналитически: $n_{\text{Т},7} = 100 \cdot a / (1 - a)$, $a = 0{,}995 \cdot 0{,}999 \cdot 0{,}42$.

Конверсия толуола в ксилол определена как доля свежего толуола, превращённая в ксилол. По стехиометрии из двух молекул толуола одна становится ксилолом (принимает метильную группу), другая – бензолом, поэтому на 1 моль ксилола расходуется 1 моль толуола «в ксилол»:

$$X_{\text{Т} \rightarrow \text{К}} = \frac{n_{\text{К},6}}{n_{\text{Т},1}}, \qquad X_{\text{Т}} = \frac{n_{\text{Т},1} - n_{\text{Т},4} - n_{\text{Т},6}}{n_{\text{Т},1}},$$

где $X_{\text{Т} \rightarrow \text{К}}$ – конверсия толуола в ксилол; $X_{\text{Т}}$ – общая конверсия толуола по схеме; $n_{\text{К},6}$ – ксилол в продуктовом потоке 6, моль/ч; $n_{\text{Т},j}$ – толуол в потоке $j$, моль/ч.

**Программа.**

```python
MW = {"C7H8": 7 * 12.011 + 8 * 1.008,       # молярные массы, г/моль
      "C6H6": 6 * 12.011 + 6 * 1.008,
      "C8H10": 8 * 12.011 + 10 * 1.008}

def t5z2(F1=100.0, conv=0.58, tol=1e-12):
    n1 = np.array([F1, 0.0, 0.0])                     # толуол, бензол, ксилол, моль/ч
    # реактор: n3 = M·n2 (прореагировало conv·T2 толуола;
    # образовалось бензола и ксилола — по conv·T2/2)
    M = np.array([[1 - conv, 0, 0], [conv / 2, 1, 0], [conv / 2, 0, 1]])
    # доли компонентов потока 3, уходящие в поток 4
    a4 = np.array([0.001, 0.995, 0.0])
    # доли компонентов потока 5, уходящие в поток 7
    a7 = np.array([0.995, 1.0, 0.001])
    G = np.diag(a7) @ np.diag(1 - a4) @ M             # n7 = G·(n1 + n7)
    # (а) метод простой итерации по разрываемому потоку 7 (как в практике 5)
    n7, hist = np.zeros(3), []
    for it in range(1, 500):
        new = G @ (n1 + n7)
        hist.append((it, *new))
        if np.max(np.abs(new - n7)) < tol:
            n7 = new
            break
        n7 = new
    iters = it
    # (б) прямое решение линейной системы (I − G)·n7 = G·n1
    n7_lin = np.linalg.solve(np.eye(3) - G, G @ n1)
    n2 = n1 + n7_lin
    n3 = M @ n2
    n4 = a4 * n3
    n5 = n3 - n4
    n7 = a7 * n5
    n6 = n5 - n7
    dR = n3 - n2                                      # изменение в реакторе
    # степень полноты реакции, моль/ч
    xi = conv * n2[0] / 2
    streams = {"1": n1, "2": n2, "R": dR, "3": n3, "4": n4, "5": n5, "6": n6, "7": n7}
    out = n4 + n6
    nu = np.array([-2.0, 1.0, 1.0])
    bal = n1 - out + nu * xi                          # покомпонентный баланс схемы
    nodes = np.concatenate([n1 + n7 - n2, n3 - n4 - n5, n5 - n6 - n7])
    atoms_C = np.array([7, 6, 8])
    atoms_H = np.array([8, 6, 10])
    mw = np.array([MW["C7H8"], MW["C6H6"], MW["C8H10"]])
    return dict(streams=streams, xi=xi, iters=iters, hist=np.array(hist), n7_iter=n7,
                n7_diff=np.max(np.abs(np.array(hist[-1][1:]) - n7_lin)),
                bal=bal, nodes=nodes,
                dC=atoms_C @ n1 - atoms_C @ out, dH=atoms_H @ n1 - atoms_H @ out,
                dm=mw @ n1 - mw @ out, mass_in=mw @ n1,
                conv_total=(n1[0] - out[0]) / n1[0], conv_to_xylene=n6[2] / n1[0],
                conv_to_benzene=n4[1] / n1[0], yield_xylene=n6[2] / (n1[0] / 2),
                recycle_ratio=n7.sum() / n1.sum(), conv=conv)
```

5. Материальные балансы схем без реакций и с рециклом сводятся к системам линейных уравнений; обусловленность матрицы определяет требования к точности исходных данных.

Для проверки результатов подготовлен скрипт check.py: он независимо пересчитывает ключевые величины, проверяет суммы мольных долей, невязки равновесий и материальных балансов и завершается с ошибкой при любом расхождении.
