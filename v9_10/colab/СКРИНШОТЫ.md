# Скриншоты из Google Colab для отчёта

Зачем: задание в Moodle требует «скриншоты из программ, использованных для решения». Код в отчёте уже вставлен текстом (это разрешено п. 3 требований), а **результаты работы программы** нужно показать скриншотами из Colab. Все результаты выводятся в **одном месте – в предпоследней ячейке блокнота**, поэтому снимать нужно только её.

## Подготовка (5 мин)

1. Открыть colab.research.google.com, войти в Google-аккаунт.
2. **Файл → Загрузить блокнот** → `МХТП_Тютюльник_вар10.ipynb` (или `МХТП_Остапов_вар9.ipynb` – код одинаковый).
3. **Инструменты → Настройки → Сайт → Тема: светлая (light)** – по требованию п. 3 фон должен быть светлым.
4. Масштаб браузера **100 %** (Ctrl+0), одна и та же ширина окна для всех снимков – тогда шрифт на всех скриншотах одинаковый (тоже п. 3).
5. **Среда выполнения → Выполнить все** (Ctrl+F9), подождать ≈ 10–20 с. Ячейки с задачами ничего не печатают – так и задумано.

## Съёмка (≈ 20 мин)

Прокрутить в конец блокнота до ячейки `# Результаты всех задач`. Под ней 14 блоков; каждый начинается строкой

```
==============================================================================
Задача 1.1
==============================================================================
```

Один блок = один скриншот: от заголовка с «=====» до последней строки блока. Сохранить PNG под именем из таблицы ниже. При вставке в отчёт заголовок блока обрезается – остаются только строки результата. Если блок не помещается на экран – два снимка: `имя_1.png`, `имя_2.png` (например, `t32_study_1.png`, `t32_study_2.png`).

Инструмент: Windows – Win+Shift+S (выделить область), затем сохранить из уведомления как PNG; macOS – Cmd+Shift+4.

Прислать 14 файлов в чат (можно одним архивом). Я положу их в `report/screens/`, пересоберу отчёт – в каждом разделе «Результат работы программы» текст заменится скриншотом – и выдам новые DOCX и PDF.
