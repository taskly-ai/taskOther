# Модуль 4. САПР Aspen HYSYS: сепарационный блок задачи 3.2 (варианты 9 и 10)

Модуль баллов не даёт (слайд 2 лекции 1). Кейс строите вы сами в HYSYS; здесь – эталонный расчёт на Python и список чисел для сверки. HYSYS не эмулируется.

## Эталонная модель

- Уравнение состояния **Пенга–Робинсона** (тот же пакет, что Fluid Package «Peng-Robinson» в HYSYS), классические правила смешения, **k_ij = 0**.
- Константы Tc, Pc, ω – справочник IFP, раздел A2 (CH₄ 190.6 К, 45.4 атм, 0.008; C₂H₆ 305.4, 48.2, 0.098; C₃H₈ 369.8, 41.9, 0.152; i-C₄H₁₀ 408.1, 36.0, 0.176; n-C₄H₁₀ 425.2, 37.5, 0.193; n-C₅H₁₂ 469.6, 33.3, 0.251).
- Флеш: последовательные подстановки от K Вильсона + уравнение Рачфорда–Райса; однофазные состояния подтверждены тестом стабильности Михельсена.
- Контроль реализации: давление насыщения пропана при −42.1 °C по PR = 101.9 кПа (опыт 101.3 кПа).
- Скрипт: `python solutions/m4/solve.py`.

Ожидаемые расхождения с HYSYS: в HYSYS PR свои k_ij (≈ 0.01–0.03) и свои константы из базы → доли пара могут отличаться в 2–3-м знаке. Однофазный сепаратор HYSYS может показать с Vapour Fraction 0 или 1 (плотную фазу он сам называет газом или жидкостью).

## Вывод для защиты

По уравнению Пенга–Робинсона при давлениях 8.7–9.8 МПа смесь находится вблизи крикондебары: при 40.8 °C она однофазна (выше точки росы), при −40.8 °C – тоже однофазна (плотная жидкоподобная фаза), и двухфазное разделение даёт только ступень при 12.8 °C. Поэтому по PR результат от числа сепараторов почти не зависит – работает одна ступень. Корреляция задания (номограммы ДеПриестера, примерно до 7 МПа) этого не учитывает и даёт разделение во всех ступенях. Расхождение ожидаемое и подтверждает оговорку в отчёте: при таких давлениях результаты задачи 3.2 оценочные, а схему сепарации нужно проверять строгой термодинамической моделью.

## Построение кейса в Aspen HYSYS (V11–V15)

1. **Properties → Component Lists → Add**: Methane, Ethane, Propane, i-Butane, n-Butane, n-Pentane.
2. **Fluid Packages → Add → Peng-Robinson**; привязать список компонентов. Перейти в **Simulation**.
3. Поток **Feed**: Temperature 40.8 °C, Pressure 9800 kPa, Molar Flow 100 kgmole/h; Composition (Mole Fractions) 0.72211 / 0.03608 / 0.22363 / 0.00646 / 0.00466 / 0.00706.
4. **Separator V-100** (С1): Inlet = Feed; Vapour = G1; Liquid = L1.
5. **Cooler E-100**: Inlet = G1; Outlet = S2; Delta P = 1100 kPa; T(S2) = 12.8 °C. **Separator V-101** (С2): Inlet = S2; Vapour = G2; Liquid = L2.
6. **Cooler E-101**: Inlet = G2; Outlet = S3; Delta P = 0; T(S3) = −40.8 °C. **Separator V-102** (С3): Inlet = S3; Vapour = Gas; Liquid = L3.
7. Схемы с меньшим числом ступеней: скопировать поток Feed (Copy/Paste → Feed-2) и собрать на нём нужную цепочку, например для «С2 + С3» – Cooler до 12.8 °C и 8700 kPa → сепаратор → Cooler до −40.8 °C → сепаратор; для «1: С3» – один Cooler до −40.8 °C и 8700 kPa → сепаратор.
8. Для каждой схемы выписать Vapour Fraction на входе каждого сепаратора и расход/состав газа последней ступени в таблицу выше; скриншоты: PFD и Worksheet → Composition.
