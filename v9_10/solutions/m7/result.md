| Всего, kgmole/h | 2.8309 | |

Ожидание: совпадение до 3–4-го знака, если Basis = Partial Pressure и единицы Keq согласованы (в HYSYS по умолчанию кПа; можно сменить Basis Units на atm и ввести 0.05). Если записать реакцию с целыми коэффициентами (N₂ + 3H₂ ⇄ 2NH₃), Keq = 0.0025 атм^−2^ = 2.4350∙10^−7^ кПа^−2^.

**Построение:** Component List: Nitrogen, Hydrogen, Ammonia → Fluid Package Peng-Robinson (при Basis = Partial Pressure пакет на константу не влияет) → Reactions → Add Set → Add Reaction → Equilibrium: стехиометрия N₂ −0.5, H₂ −1.5, NH₃ 1; вкладка Basis: Basis = Partial Pressure, Keq Source = Fixed Keq, значение по таблице → Add Set to Fluid Package. Simulation: поток Feed 589 K (315.85 °C), 22 291.5 кПа (220 атм), 4.3 kgmole/h, мольные доли 0.2558 / 0.6977 / 0.0465 (= 1.1/4.3, 3/4.3, 0.2/4.3) → Equilibrium Reactor, Reaction Set, выход изотермический (T продукта 589 K). Скриншоты: PFD, Reactions → Results.
