# Скриншоты из Google Colab для отчёта

Требования: скриншоты программ обязательны (задание в Moodle, п. 1 требований); код – на светлом фоне, одного масштаба по всему отчёту (п. 3). Сейчас в отчёте код и вывод вставлены текстом (это тоже разрешено п. 3); присланные скриншоты автоматически заменят текст.

## Подготовка (5 мин)

1. Открыть colab.research.google.com, войти в Google-аккаунт.
2. **Файл → Загрузить блокнот** → файл `out/МХТП_Филимонов_вар1.ipynb` (из репозитория).
3. **Инструменты → Настройки → Сайт → Тема: светлая (light)**. Сохранить.
4. Масштаб браузера **100 %** (Ctrl+0) и одна и та же ширина окна для всех снимков – тогда шрифт кода одинаковый.
5. **Среда выполнения → Выполнить все** (Ctrl+F9). Дождаться выполнения всех ячеек (≈ 10 с). Если первая ячейка выдаст ошибку импорта – просто перезапустить «Выполнить все».

## Съёмка (≈ 30–40 мин)

Для каждой ячейки – один снимок: код ячейки + текстовый вывод под ним («Результат работы программы»). График в снимок включать не нужно: те же графики уже стоят в отчёте как рисунки с подписями. Если ячейка не помещается на экран – два снимка: `имя_1.png` (код) и `имя_2.png` (продолжение и вывод).

Инструмент: Windows – Win+Shift+S (область), сохранить как PNG; macOS – Cmd+Shift+4.

## Отправка

Пришлите файлы в чат (можно архивом), назвав их по таблице. Я положу их в `report/screens/`, пересоберу отчёт (`python report/build.py`) и выложу обновлённые DOCX и PDF. Снимки вставляются по ширине 16.5 см, без подписи (п. 8 требований разрешает не подписывать скриншоты кода).
