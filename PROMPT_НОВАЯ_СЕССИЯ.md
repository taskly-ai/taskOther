## Механика кода (важно, иначе Colab ломается)

- Ячейки блокнота разделяются строкой `# %%` в `solve.py`; `runner.py` собирает их в `.ipynb`.
- Задачи ничего не печатают сразу. В начале задачи вызывается `task("t11", "Задача 1.1")`, вывод идёт через `report(...)`, графики через `draw(fig, "o11")`. В конце блокнота ячейка `show_results()` печатает все 14 блоков, `show_figures()` показывает графики.
- Ключи блоков: `t11 t12 t13 t14 t21 t22 t31 t32 t32_study t41 t42a t42b t51 t52`.
- Длина строки вывода ≤ 89 символов (иначе скриншот не помещается).
- Не использовать в разных ячейках одинаковые имена для разного смысла (раньше ломалось: `out`, `stages`).
- После сборки блокнот выполнить через `nbclient` и убедиться, что нет ошибок и вывод совпадает с `report.md`.

## Сборка

Из папки образца: `python report/build.py` → расчёт, `report.md`, DOCX (pandoc + `reference.docx`, доводка python-docx: титул, рамки таблиц, «∙», шрифт кода), линтер, PDF через LibreOffice (UNO, с обновлением содержания), `.ipynb`. Потом собрать zip.

Нужны: pandoc, LibreOffice (writer + math), python-docx, numpy ≥ 2, scipy, matplotlib, pillow, nbformat, nbclient. Если чего-то нет в контейнере – установить.

## Принятые решения по аномалиям задания

- 1.1: в шапке «C, кДж/кг К», но значения – мольная теплоёмкость пропана в Дж/(моль∙К) (проверено по справочнику IFP, раздел D1). Считать в Дж/(моль∙К), в тексте объяснить; в шапках таблиц писать единицу.
- 1.4: прочерки в таблице вязкости – точек нет, их исключать и оговаривать.
- 3.x: K-корреляция задания в °R и psia (T_R = 1.8∙T_K, P_psia = P_Pa/6894.757); «C4», «C5» – н-бутан, н-пентан; схема 3.2 – только на `zadachi_p-5.png`.
- 4.2а: ΔG°f в справочнике до 1000 К; K(1100 К) – Вант-Гофф от 1000 К или Кирхгоф от 298 К с Cp из D1 (сравнение с табличными ΔG° при 1000 К обязательно).
- 5.2: «кислол» = ксилол (C8H10); столбец «R» – реактор; конверсия за проход 58 %. «Конверсия толуола в ксилол» = X6/T1 (предел 50 %) с оговоркой про второе прочтение 2∙X6/T1.
- Справочные константы: критические параметры – IFP A2 (`extracted/ifp_A2_layout.txt`), Cp/ΔH°f/ΔG°f – IFP D1/E18/E19 (`extracted/ifp_D1_E18_E19_layout.txt`). R = 8.314462618 в расчёте, в подстановках писать 8.3145.

## Ошибки, которые уже ловили (не повторять)

- Нумерация таблиц: `Counter` в `text.py` нумерует в порядке **создания** строк таблиц, поэтому создавать таблицы в том же порядке, в каком они стоят в тексте.
- Не писать «выпуклая кривая» без проверки знака второй производной; не писать «на столько-то %», «тот же R²», «лучше при меньшем числе параметров» без проверки по числам.
- Число параметров полинома степени d равно d + 1.
- В задаче 4.1 при ξ = 2 кончается только водород (азота остаётся 0.1 моль/ч).
- Проверки вида K = y1∙y2/y0 показывать с таким числом знаков, чтобы арифметика сходилась.
- Модель Фогеля–Фулчера дала отрицательный T0 – физически негодна; не использовать без проверки.
- Критерий выбора схемы/режима в 3.2 формулировать явно (например, C3+ в газе ≤ 0.3 %).
- «Сверхкритическая область» при T_pr > 1, а не «вблизи критической точки».
