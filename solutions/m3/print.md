# Печать и оформление – модуль M3

Источник требований: `Требования_к_оформлению_отчета.docx` (извлечение – `extracted/Требования_к_оформлению_отчета.docx.md`). ГОСТ в файлах кафедры не упоминается; ниже отмечено, что взято из файла, а что принято как допущение.

| Параметр | Значение | Источник |
|---|---|---|
| Формат | A4, книжная | свойства раздела файла требований: 210 × 297 мм |
| Поля | левое 30, правое 15, верхнее 20, нижнее 20 мм | свойства раздела файла требований |
| Шрифт основного текста | Times New Roman | требование 2 |
| Кегль, интервал, абзацный отступ | 14 пт, 1.5, 1.25 см – одинаковые по всему отчёту | требование 2 требует только единообразия; конкретные значения – **допущение** (как в готовом титуле) |
| Выравнивание | текст – по ширине; рисунки – по центру | требование 2 |
| Код | скриншоты Colab на светлом фоне одного масштаба или текст другим шрифтом (Courier New 9 пт) | требование 3 |
| Формулы | только редактор формул Word; «∙» вместо «*»; степени надстрочные | требования 4–5 |
| Таблицы | подпись «Таблица N – …» над таблицей, справочные данные со ссылкой [N] | требование 6 |
| Рисунки | подписи осей с единицами, легенда, «Рисунок N – …» под рисунком, пустая строка после подписи | требование 8 |
| Тире/дефис | «–» с пробелами; в диапазонах без пробелов (17–33 мм) | требование 9 |
| Десятичный разделитель | точка во всём отчёте (как в исходных данных) | требование 10 (единообразие) |
| Список литературы | по порядку ссылок, оформление по ГОСТ Р 7.0.100-2018 – **допущение** | требование 7 |
| Титул | текст «Отчет по решению задач за 7 семестр по курсу Моделирование химико-технологических процессов» | задание Moodle |

Сдача: файл `out/МХТП_Отчет_7сем_Филимонов_вар1.docx` загружается в Moodle (не в личный кабинет ОмГТУ). Печать в файлах курса не требуется. Если преподаватель попросит бумажный экземпляр: односторонняя печать A4, без масштабирования («Фактический размер»), титул без номера страницы, подпись и дата в строке «Выполнил», скоросшиватель.
