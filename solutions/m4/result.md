# Модуль 4. САПР Aspen HYSYS: сепарационный блок задачи 3.2 (вариант 1)

Модуль баллов не даёт (слайд 2 лекции 1). Кейс строите вы сами в HYSYS; здесь – эталонный расчёт на Python и список чисел для сверки. HYSYS не эмулируется.

## Эталонная модель

- Уравнение состояния **Пенга–Робинсона** (тот же пакет, что Fluid Package «Peng-Robinson» в HYSYS), классические правила смешения, **k_ij = 0**.
- Константы Tc, Pc, ω – справочник IFP, раздел A2 (CH₄ 190.6 К, 45.4 атм, 0.008; C₂H₆ 305.4, 48.2, 0.098; C₃H₈ 369.8, 41.9, 0.152; i-C₄H₁₀ 408.1, 36.0, 0.176; n-C₄H₁₀ 425.2, 37.5, 0.193; n-C₅H₁₂ 469.6, 33.3, 0.251).
- Флеш: последовательные подстановки от K Вильсона + уравнение Рачфорда–Райса; однофазные состояния подтверждены тестом стабильности Михельсена.
- Контроль реализации: давление насыщения пропана при −42.1 °C по PR = 101.9 кПа (опыт 101.3 кПа).
- Скрипт: `python solutions/m4/solve.py`.

Ожидаемые расхождения с HYSYS: в HYSYS PR свои k_ij (CH₄–C₃H₈ и др. ≈ 0.01–0.03) и свои константы из базы → доли отгона могут отличаться в 2–3-м знаке. Если HYSYS показывает Vapour Fraction 0 или 1 у однофазного сепаратора – это то же «однофазно» (HYSYS сам решает, называть плотную фазу газом или жидкостью).

## Вывод для защиты

По уравнению Пенга–Робинсона сырьё при 9.8 МПа двухфазно только в узком интервале t₁ ≈ 0–15 °C, а при −40.8 °C и 8.7 МПа газ С2 переходит в однофазное плотное состояние: давление 8.7–9.8 МПа близко к крикондебаре смеси. Корреляция задания (номограммы ДеПриестера, примерно до 7 МПа) этого не учитывает и даёт двухфазное разделение во всех сепараторах. Расхождение ожидаемое и подтверждает оговорку в отчёте: результаты задачи 3.2 при таких давлениях оценочные, а режим сепарации нужно проверять строгой термодинамической моделью.

## Построение кейса в Aspen HYSYS (V11–V15)

1. **Properties → Component Lists → Add**: Methane, Ethane, Propane, i-Butane, n-Butane, n-Pentane.
2. **Fluid Packages → Add → Peng-Robinson**; привязать список компонентов. Перейти в **Simulation**.
3. Поток **Feed**: Temperature 40.8 °C, Pressure 9800 kPa, Molar Flow 100 kgmole/h; Composition (Mole Fractions) 0.72211 / 0.03608 / 0.22363 / 0.00646 / 0.00466 / 0.00706.
4. **Separator V-100**: Inlet = Feed; Vapour = G1; Liquid = L1.
5. **Cooler E-100**: Inlet = G1; Outlet = S2; Delta P = 1100 kPa; на вкладке Worksheet задать Temperature S2 = 12.8 °C; Energy = Q1.
6. **Separator V-101**: Inlet = S2; Vapour = G2; Liquid = L2.
7. **Cooler E-101**: Inlet = G2; Outlet = S3; Delta P = 0; T(S3) = −40.8 °C; Energy = Q2.
8. **Separator V-102**: Inlet = S3; Vapour = Gas; Liquid = L3.
9. Выписать Vapour Fraction потоков Feed, S2, S3 и составы G1/L1, G2/L2, Gas/L3 в таблицы выше; скриншоты: PFD, Worksheet → Composition для трёх сепараторов.
10. **Home → Case Studies → Add**: независимая переменная Feed → Temperature, от −10 до 90 °C, шаг 5; зависимые – Gas → Molar Flow, Vapour Fraction S2 и S3. Run → вкладка Plots → скриншот графика.
