# Образец решения МХТП, 7 семестр, вариант 10 (альтернативный способ решения)

Обезличенный образец (без ФИО и зачётки). Данные – строка «9 и 10» задания; результаты, однозначно следующие из данных, совпадают с основным решением в `v9_10/`, отличается ход решения:

| Задача | Основное решение (`v9_10`) | Образец (`obrazets_v10`) |
|---|---|---|
| 1.1 | Polynomial.fit, трапеции | МНК по τ = T/1000 (lstsq), оценка обусловленности, трапеции вручную + Симпсон |
| 1.2 | curve_fit; альтернативы – степенная (НМНК), экспонента | least_squares; альтернативы – гипербола и степенная в логарифмах (линейный МНК) |
| 1.3 | линеаризация + НМНК по k, локальные Ea | линеаризация матрично, МНК по относительным ошибкам, два участка |
| 1.4 | полиномы по T, уравнение Андраде | полиномы по z = (T − 330)/60, F-критерий, ln μ = A + B/T + C/T² |
| 2.1–2.2 | numpy.roots, RK/SRK | метод Ньютона от Z₀ = 1, RK/SRK/PR, изотермы Z(P) |
| 3.1 | метод Брента | метод секущих по ln ΣKz, фазовая диаграмма 4–30 атм |
| 3.2 | бисекция/brentq для Р–Р, 6 схем | метод Ньютона для Р–Р, покомпонентный баланс, ряды А и Б |
| 4.1 | метод Брента | полином 4-й степени по ξ, влияние давления |
| 4.2а | Вант-Гофф от 1000 К (K = 1.671) | Кирхгоф от 298 К с Cp из D1 (K = 1.677), проверка при 1000 К |
| 4.2б | fsolve | сведение к одному уравнению (квадратное по x₂ + Брент) |
| 5.1 | numpy.linalg.solve | собственный метод Гаусса, степени извлечения |
| 5.2 | линейная система 14×14 | последовательный модульный расчёт, простая итерация и Вегстейн |
